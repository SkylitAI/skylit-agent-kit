# Optional FRED connection

Follow the [Federal Reserve Bank of St. Louis setup guide](https://fredhelp.stlouisfed.org/fred/data/ai/fred-mcp-connector/) for its official MCP connector and current supported hosts. Use your own free FRED account; the official connector uses sign-in rather than a FRED API key.

This is an optional profile, not a bundled MCP server or an automatically activated connection. Record host/version and successful retrieval before claiming support. Preserve series units, observation dates and source metadata. FRED [terms](https://fred.stlouisfed.org/legal/) and third-party series rights still apply. The offline sample works without this connection.
