# Claude repository entry point

Read [AGENTS.md](AGENTS.md) first; it contains the shared instructions and source boundary.

For onboarding, follow [Start here](docs/start-here.md): run the offline node tracker and show its chart before suggesting live setup. Use the [capability map](docs/capabilities.md) to route the next question to existing commands and recipes. The [Claude setup guide](agents/claude/README.md) separates local workflows from optional direct MCP.

Keep the session scoped to this repository. Do not attach private vault context, infer live authorization, search for keys or reconstruct proprietary formulas. Honor already-authorized scope without redundant approvals.
