# From community experiment to maintained starter

| Home | What to submit |
|---|---|
| [Agent Lab](https://github.com/SkylitAI/skylit-agent-lab) | Experimental workflows, integrations, tools, demos and evaluations |
| [Agent Kit](https://github.com/SkylitAI/skylit-agent-kit) | Fixes, tutorials, maintained examples and reviewed promotions |

An experiment should describe its owner, purpose, setup, host/version, required access, costs, sample output, limitations and maturity. Suggested states: experimental, reproducible, graduated, archived. Staying in the lab is a valid outcome.

Promotion requires a useful demonstrated workflow, reproducible setup, relevant tests, license/attribution notes, bounded behavior, documentation and a named maintainer. Submit a kit pull request with evidence; preserve contributor credit and link the lab entry to the maintained version.

The kit never depends on unreleased lab code. Lab work should reuse a released kit component where practical. Experimental status does not waive credential handling, API limits or source rights. Both repositories are public, so anyone can open an issue or pull request.
